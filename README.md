## 📖 About This Project

This was one of my very first hands-on projects when I was learning **HTML, CSS, and JavaScript** — before React, before backend, before any of the bigger projects in my other repos. It's a simple number guessing game: the computer picks a random number between 1 and 10, and you try to guess it, with your score dropping a little on every wrong try.

Nothing fancy here — just three files, plain vanilla JavaScript, and a lot of trial and error to get it working.

---

## 🎯 Why I Built This

Around this time, I was just getting comfortable with the basics — variables, functions, and how JavaScript actually talks to a webpage through the DOM (`document.querySelector`, event listeners, and so on). I wanted something small and fun to actually *build*, instead of just reading tutorials, and a number guessing game felt like the perfect size: simple rules, but enough logic to force me to think through conditions, comparisons, and updating the page in real time.

This was also the first time I learned how to take a project from my own computer and **push it to GitHub**, and then turn it into a live website using **GitHub Pages** — seeing my own tiny game go live on a real URL for the first time was a pretty exciting moment back then.

---

## 🕹️ How to Play

- The computer secretly picks a random number between **1 and 10**.
- Type your guess into the input box and click **Check**.
- You'll be told if your guess is too **high** or too **low**.
- Every guess costs you a point off your score (starting at 20).
- Guess the correct number to win — or hit **Reset** to start over.
